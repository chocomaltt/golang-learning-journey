# Golang Learning Journey
This repository is created for learning purposes. There will be 15 folders within this repository, and each folder represent one jobsheet.<br><br>
Why? because I'm tired of being stupid 😭.

---
Within this repository, you'll find these:
1. **Jobsheet 1 - Setup Environment & Go Fundamentals**<br>
It's a basic one, you'll learn about how to setup Golang on your local machine. You'll also learn couple of commands like ```go mod init```, ```go run .```, ```go fmt```, and so on. Finding hello world tutorial? Knock his door here.
2. **Jobsheet 2 - Structs, Methods & Interfaces**<br>
You'll learn how Structs works and looks like in Golang. Interfaces like the one you learn on Java? Yes, you'll meet interfaces here too. There's 2 types of interface, implicit and composition.
3. **Jobsheet 3 - Collections, Generics & Error Handling**<br>
Level up! Meet ```slice```, ```map```, ```generic```, and ```error```. Don't be scared of error, you'll love it sometimes (it's a love hate situation btw). In this jobsheet you'll learn about what's the different between ```slice``` and ```map```.<br>
You'll also learn about this ```[]T```, ```[T any]```, ```[T, U any]```, and so on. This concept will save you a lot of time once you jump into a real project.
